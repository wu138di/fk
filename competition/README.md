# 开源鸿蒙星闪智能复合机器人挑战赛 · 竞赛资料说明

> 当前仓库中尚未包含竞赛资料包原文件。请按照下方步骤将资料上传到仓库，以便团队协作查阅和解析。

---

## 一、要做什么

参加 **2026 广东省大学生计算机设计大赛 · OH-星闪智能复合机器人挑战赛**（预选赛）。

核心任务：在 **DevEco Studio** 中完成三个代码模块，最终提交源码包 + 演示视频。

| 模块 | 名称 | 核心工作 |
|------|------|---------|
| **A** | 模块导入 | 在基础工程里导入指定外部 API 模块，调用接口并能正常构建 |
| **B** | 应用界面设计 | 编写代码完成页面布局、按钮点击与交互事件 |
| **C** | 数据解析 | 输入指定数据，解析后将各字段展示在页面中 |

满分 **100 分**，本科组与高职组考核方式相同。

---

## 二、怎么做

1. **环境准备**
   - 安装 [DevEco Studio](https://developer.harmonyos.com/cn/develop/deveco-studio/) 最新版
   - 配置 OpenHarmony SDK（建议 6.0 Beta1 或以上）
   - 下载组委会统一下发的**参考源码包**（见下方"如何上传资料"）

2. **按模块顺序开发**
   - 模块 A：找到 `oh-package.json5`，添加外部模块依赖，执行 `ohpm install`，确认构建通过
   - 模块 B：在 `.ets` 页面文件中编写 `@Component`，实现 UI 布局和 `onClick` 事件
   - 模块 C：接收指定格式数据（JSON/字符串），解析出各字段，用 `Text()` 或列表组件展示在界面上

3. **录制演示视频**
   - 模块 A、B、C 各录一段，每段 **≤ 2 分钟**
   - 视频需清晰展示功能运行效果（推荐使用模拟器录屏）

## 三、交什么

提交材料（电子版）需包含以下全部内容：

```
submission/
├── info.md            # 参赛队伍基本信息（学校/学院名称、成员信息、作品名称）
├── src/               # 完整源码包（含模块 A/B/C 代码）
│   └── ...
├── video_A.mp4        # 模块 A 演示视频（≤2 分钟）
├── video_B.mp4        # 模块 B 演示视频（≤2 分钟）
└── video_C.mp4        # 模块 C 演示视频（≤2 分钟）
```

## 五、容易丢分点

| 风险点 | 说明 |
|--------|------|
| 模块 A 构建失败 | 外部模块未正确写入 `oh-package.json5` 或版本号错误，导致 `ohpm install` 报错 |
| 模块 B 页面空白 | 组件未在 `@Entry` 页面入口注册，或 `build()` 方法结构不完整 |
| 模块 C 解析数据为空 | 数据格式与组委会指定的不一致，或解析逻辑未覆盖边界情况 |
| 视频超时或无声 | 超过 2 分钟会被评委忽略；录屏无声音会影响操作步骤说明效果 |
| 队伍信息填写不完整 | 缺少学院名称、作品名称或成员信息，可能导致作品无效 |
| 源码包不完整 | 提交前请确认源码可在全新环境中正常构建（不依赖本地绝对路径） |

## 如何将竞赛资料包上传到本仓库

如果你手上有组委会下发的"资料包"（`.zip` 或文件夹），请按以下步骤上传：

```bash
# 1. 克隆或拉取本仓库
git clone https://github.com/wu138di/fk.git
cd fk

# 2. 在 competition/ 目录下放入资料包原文件
#    例如：将解压后的内容放到 competition/materials/ 目录
cp -r ~/Downloads/竞赛资料包/* competition/materials/

# 3. 提交并推送
git add competition/materials/
git commit -m "feat: 添加竞赛资料包原文件"
git push origin master
```

上传后，资料包中的评分细则、接口说明、参考源码等即可在仓库中直接查阅，便于团队协同。
